\caption{\textbf{From one prompt to four claim-level decisions.}
The task context fixes a truth contract with the attached archive extract $O_p$
and three further fields. The model response is segmented into spans; only
truth-conditional spans yield canonical claims. Each claim is compared with
$O_p$, then assigned a contract label. Figurative wording is handled during
claim recovery and does not create a fourth label. The archive extract and the name
``Chapuis'' are constructed for this example.}
